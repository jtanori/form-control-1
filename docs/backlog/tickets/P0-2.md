## Summary

Implement `@vfe/protocol`: the single shared contract between **any** client (Chrome extension today; desktop/mobile later) and the Brain. Runtime-validated with `zod`, fully typed via `z.infer`, and directly usable with OpenAI Structured Outputs.

Nothing in this package may import a DOM, Node, or browser API. It is pure data + validation.

> **This package is the critical path.** It must be merged before Tracks A–E start. Changes after merge are additive-only within `PROTOCOL_VERSION` `1.x` — see "Change policy".

## Exact schemas to implement (frozen — copy verbatim, then extend)

```ts
import { z } from 'zod';

// 1. THE EYES: Universal UI Element Representation
export const FormElementSchema = z.object({
  id: z.string().describe("Unique generated ID, e.g., 'vfe_1'"),
  badgeIndex: z.number().describe('Visual number shown to user, e.g., 1'),
  type: z.enum([
    'text', 'email', 'password', 'number', 'tel', 'date',
    'textarea', 'select', 'checkbox', 'radio', 'button', 'combobox',
  ]),
  label: z.string().describe('Resolved human-readable label'),
  placeholder: z.string().optional(),
  value: z.union([z.string(), z.boolean(), z.array(z.string())]),
  options: z.array(z.object({ label: z.string(), value: z.string() })).optional(),
  required: z.boolean(),
  disabled: z.boolean(),
  focused: z.boolean(),
  validationError: z.string().optional().describe('Visible error message attached to field'),
  groupLabel: z.string().optional().describe("Fieldset legend or section header, e.g., 'Shipping Address'"),
});

export const PageStateSchema = z.object({
  urlOrAppTitle: z.string(),
  elements: z.array(FormElementSchema),
  globalErrors: z.array(z.string()).optional(),
});

// 2. THE HANDS: Universal Action Output from LLM
export const ActionSchema = z.discriminatedUnion('action', [
  z.object({ action: z.literal('FILL'), targetId: z.string(), value: z.string() }),
  z.object({ action: z.literal('SELECT'), targetId: z.string(), value: z.string() }),
  z.object({ action: z.literal('SET_CHECKED'), targetId: z.string(), checked: z.boolean() }),
  z.object({ action: z.literal('CLICK'), targetId: z.string() }),
  z.object({ action: z.literal('FOCUS'), targetId: z.string() }),
  z.object({ action: z.literal('CLEAR'), targetId: z.string() }),
  z.object({ action: z.literal('SCROLL'), direction: z.enum(['up', 'down', 'top', 'bottom']) }),
  z.object({ action: z.literal('ASK_CLARIFICATION'), questionToUser: z.string() }),
]);

export const BrainResponseSchema = z.object({
  thoughtProcess: z.string().describe('Brief reasoning about what the user wants'),
  spokenFeedback: z.string().optional().describe('Short confirmation or question to speak via TTS'),
  actions: z.array(ActionSchema),
});
```

### Required extensions (gaps in the blueprint that the tracks need on day 1)

```ts
// Envelope sent by the client to POST /api/process-command
export const ConversationTurnSchema = z.object({
  role: z.enum(['user', 'assistant']),
  text: z.string().max(4000),
  at: z.number().int().describe('epoch ms'),
});

export const ProcessCommandRequestSchema = z.object({
  pageState: PageStateSchema,
  transcript: z.string().min(1).max(2000),
  conversationHistory: z.array(ConversationTurnSchema).max(20).default([]),
  clientContext: z.object({
    client: z.enum(['extension', 'desktop', 'mobile', 'testbed']),
    clientVersion: z.string(),
    protocolVersion: z.string(),
    locale: z.string().optional(),      // BCP-47, e.g. 'en-US'
    timezone: z.string().optional(),    // IANA, for date parsing
  }).optional(),
}).strict();

export const ProcessCommandResponseSchema = z.object({
  brainResponse: BrainResponseSchema,
  meta: z.object({
    provider: z.string(),
    model: z.string(),
    latencyMs: z.number(),
    requestId: z.string(),
  }),
});

// Shared HUD/agent state (used by E-1, INT-1, INT-2)
export const AgentStatusSchema = z.enum([
  'idle', 'listening', 'thinking', 'executing', 'clarifying', 'error',
]);

// Execution result surfaced to the HUD (produced by B-3)
export const ActionErrorCodeSchema = z.enum([
  'ELEMENT_NOT_FOUND', 'ELEMENT_DISABLED', 'ELEMENT_NOT_FILLABLE',
  'OPTION_NOT_FOUND', 'VALUE_MISMATCH', 'VALUE_INVALID', 'TIMEOUT', 'ABORTED',
]);

export const ActionResultSchema = z.object({
  action: ActionSchema,
  ok: z.boolean(),
  error: z.object({
    code: ActionErrorCodeSchema,
    message: z.string(),
    details: z.record(z.unknown()).optional(),
  }).optional(),
  warnings: z.array(z.string()).default([]),
  durationMs: z.number(),
});
```

### Required constant and helpers

```ts
export const PROTOCOL_VERSION = '1.0.0';

/** Parse + throw a typed ProtocolError carrying the flattened issues. */
export function parseBrainResponse(input: unknown): BrainResponse;
export function parsePageState(input: unknown): PageState;

export class ProtocolError extends Error {
  readonly code: 'INVALID_PAGE_STATE' | 'INVALID_BRAIN_RESPONSE' | 'UNSUPPORTED_VERSION';
  readonly issues: Array<{ path: string; message: string }>;
}
```

- `parse*` must call `safeParse` and convert `ZodError.issues` → `issues` (`path.join('.')`).
- Never use `z.preprocess`, `z.transform`, or `z.coerce` on wire types: transformed schemas cannot be emitted as JSON Schema / Structured Output schema. If validation needs normalisation, do it in the Brain, not the schema.
- Every field keeps a `.describe()` — the descriptions are literally the model's field documentation in the JSON schema.

## Change policy (write this into `docs/architecture.md`)

1. **Additive only** within `1.x`: new optional fields, new union members appended.
2. Removing/renaming/re-typing a field bumps `PROTOCOL_VERSION` to `2.0.0` and requires a migration note in the PR.
3. Consumers must send `clientContext.protocolVersion`; the Brain rejects mismatched majors with `UNSUPPORTED_VERSION` + HTTP 409.
4. `packages/protocol/fixtures/*.json` are the golden samples consumed by Tracks A, B, C and QA. Editing a fixture requires updating all consumers in the same PR.

## Test plan (target: 100% line/branch/function coverage on `src/`)

1. **Happy path per action kind** — one valid object per `ActionSchema` member parses.
2. **Discriminated union rejection** — `{ action: 'FILL' }` without `value` fails; `{ action: 'SCROLL', direction: 'left' }` fails; unknown action fails.
3. **Type guards** — `FormElementSchema` rejects `type: 'submit'`, `badgeIndex: '1'` (string), missing `required`/`disabled`/`focused`.
4. **Value union** — accepts `'x'`, `true`, `['a','b']`; rejects `null`, `0`, `{}`.
5. **Envelope** — `.strict()` rejects unknown top-level keys; `conversationHistory` defaults to `[]`; transcript >2000 chars fails; >20 turns fails.
6. **ProtocolError** — `parseBrainResponse({})` throws `ProtocolError` with `issues.length > 0` and paths like `actions`.
7. **JSON Schema emission** — `zodToJsonSchema(BrainResponseSchema)` snapshot test proves the schema is Structured-Outputs-safe (no `$ref` cycles, no `transform`).
8. **Fixture conformance** — every JSON in `fixtures/` parses against its schema; fixtures are exported from `@vfe/protocol/fixtures` (subpath export) so Tracks A/B/C import the exact same bytes.
9. **Coverage gate** — `vitest.config.ts` sets `coverage.thresholds: { lines: 100, functions: 100, branches: 100, statements: 100 }` for this package and the root `pnpm test:coverage` fails if it regresses.

## Acceptance criteria

- [ ] Package exports every Zod schema **and** its inferred type (`FormElement`, `PageState`, `Action`, `BrainResponse`, `ProcessCommandRequest`, `ProcessCommandResponse`, `ActionResult`, `AgentStatus`, `ActionErrorCode`, `ConversationTurn`).
- [ ] Zod + TypeScript types compile under `strict` + `noUncheckedIndexedAccess`.
- [ ] 100% unit-test coverage on `packages/protocol/src` (enforced by threshold, not by hand).
- [ ] `zodToJsonSchema(BrainResponseSchema)` produces a valid JSON Schema without `$ref`, `transform`, or `preprocess` artifacts.
- [ ] Golden fixtures exist and are importable from other packages via `@vfe/protocol/fixtures/*`.
- [ ] `PROTOCOL_VERSION` and change policy are documented in `docs/architecture.md`.
- [ ] **No imports** of `dom`, `node:*`, `@types/node`, `openai`, or `zod-to-json-schema` in runtime `src/` (only `zod`); bundle < 15 KB gzipped (checked by `pnpm --filter @vfe/protocol size` or `du` in CI).
- [ ] Track owners can `import { PageStateSchema, type PageState } from '@vfe/protocol'` in a scratch branch without further work.

## Explicit non-goals

- HTTP transport implementation (C-1).
- Runtime message schemas for `chrome.runtime` (extension-internal, live in `packages/extension/src/messaging.ts` — they are not universal).
- Auth/session models (C-1/C-3).
- Multi-language labels or localization of `spokenFeedback` (Brain replies in the user's locale; the schema is language-neutral).

## Notes for downstream owners (read before starting)

| Track | Guarantees you can rely on | Traps |
| --- | --- | --- |
| A (Eyes) | `PageStateSchema` is exactly what `distillPage()` must return | `value` must always be set: `''` for empty text, `false` for unchecked, `[]` for multi-select |
| B (Hands) | `ActionSchema` is exactly what `executeActions()` consumes | Resolve `[data-vfe-id]` **at execution time**, not up front (SPA re-renders) |
| C (Brain) | `BrainResponseSchema` is directly usable with `zodResponseFormat` | Keep `thoughtProcess` short; it is billed output |
| D (Ears) | `AgentStatus` drives HUD, not protocol state | Audio buffers never enter the protocol — they are extension-internal |
| E (HUD) | `AgentStatus` + `ActionResult` are the only inputs needed | Never re-derive state locally; render what the orchestrator says |
